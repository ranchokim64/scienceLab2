# 💡 반짝 회로 실험실

초등학교 6학년 과학 「전기의 이용」 단원을 위한 웹 회로 실험 도구입니다.
PhET *Circuit Construction Kit: DC*의 "끌어다 놓고 이어 보는" 방식을 본떠, 초등학생 눈높이와 차시 학습 목표에 맞는 기능을 더했습니다.

- **크롬북(마우스·터치패드)과 태블릿(터치) 모두 지원**: 끌기, 두 손가락 확대/축소, 휠 확대/축소, 큰 버튼
- 설치·로그인 없이 브라우저 링크로 접속, 회로는 기기에 자동 저장

## 주요 기능

| 기능 | 설명 |
|---|---|
| 🎯 미션 모드 | 차시별 미션 6개. 미션마다 필요한 부품만 꺼낼 수 있고, 목표를 이루면 자동으로 성공을 알려 줌 |
| 🔮 예상하기 | 결과를 보기 전에 먼저 예상하고, 성공하면 "내 예상 → 실제 결과"를 비교 |
| 🤔 왜 안 켜질까? | 끊긴 곳, 열린 스위치, 빠진 전구, 반대로 놓인 전지, 합선 등을 질문 → 위치 표시 순서로 단계별 힌트 |
| ⭐ 밝기 별점 | 숫자(V, A) 대신 별 0~5개로 밝기를 보여 줌. 전지 1개 + 전구 1개 = 별 3개 |
| ⚡ 전기 흐름 보기 | 움직이는 점으로 전기가 흐르는 길과 세기를 보여 줌 |
| ⚖️ 비교하기 | 회로 두 개를 나란히 만들어 밝기 비교(직렬 vs 병렬) |
| ⚠️ 합선 경고 | 전지 두 극을 바로 이으면 전선이 빨갛게 달아오르고 안전 안내 |
| 🔊 읽어 주기 | 미션·힌트를 한국어 음성으로 읽어 줌 |
| 🧲 전자석 | 에나멜선을 감은 철못. 끌어당기는 클립 수, N·S극, 나침반으로 세기와 극을 보여 줌 |
| 📎 검사할 물체 | 철 클립·알루미늄 포일·동전·지우개·플라스틱 자·나무젓가락으로 전기가 통하는지 검사 |
| 📸 관찰 기록장 | 회로 그림과 결과를 저장하고 「알게 된 점」을 써서 활동지로 인쇄·PDF 저장 |
| 👩‍🏫 선생님 도구 | 미션·시작 회로를 담은 수업 링크와 QR(크게 보기) 만들기, 미션 잠금, 숫자 보기 |
| 🔣 회로도 / 🔢 숫자 | 회로도 기호로 보기, 전압·전류 숫자 보이기 (심화) |
| 📶 오프라인 | 한 번 열어 두면 인터넷이 끊겨도 열림 |

### 미션 목록 — 비상교육 6학년 「전기의 이용」 차시 순서 (`src/missions.ts`)

| 차시 | 미션 | 교과서 쪽수 |
|---|---|---|
| 2차시 | 1. 불을 켜라! · 2. 스위치로 켜고 끄기 | 과학 14~15 · 실험 관찰 12~13 |
| 3차시 | 3. 직렬 · 4. 병렬 · 5. 전구 하나를 빼면? | 과학 16~17 · 실험 관찰 14~15 |
| 4차시 | 6. 안전 탐정 · 7. 전기 절약 탐정 | 과학 18~19 · 실험 관찰 16~17 |
| 5~7차시 | 8. 전자석 만들기 · 9. 전자석의 세기와 극 (+ 쓰임새 조사 질문) | 과학 20~23 · 실험 관찰 18~21 |
| 8~9차시 | 10. 불이 켜지는 카드 설계하기 (창의 융합) | 과학 24~25 · 실험 관찰 22~23 |
| 더 해 보기 | 11. 전기가 통하는 물체 찾기 (교과서 밖 심화) | |

성공하면 학습 내용을 정리해 주고, 토의·조사가 필요한 차시(4차시, 7차시 등)는 「💬 이야기해 봐요」 질문이 함께 나옵니다.

> 순서·문구를 바꾸려면 `src/missions.ts`의 `MISSIONS` 배열만 고치면 됩니다.

## 조작법

- **부품 꺼내기**: 부품 상자에서 끌어다 놓거나 한 번 누르기
- **연결하기**: 부품이나 전선의 끝(동그라미)을 다른 끝 가까이 가져가면 착 붙음
- **회전**: 전지·전구·스위치의 끝을 끌면 반대쪽 끝을 중심으로 돎
- **선택 도구**: 부품을 누르면 아래에 「전구 빼기」, 「방향 바꾸기」, 「지우기」 등이 나옴. 연결된 점을 누르면 「연결 떼기」
- **스위치**: 누르면 열림/닫힘
- **화면 이동/확대**: 빈 곳을 끌어 이동, 두 손가락 벌리기·휠로 확대, ⤢ 버튼으로 회로가 다 보이게
- **되돌리기**: ↶ 버튼 또는 Ctrl+Z
- **물체 바꾸기 / 코일 감기**: 검사할 물체나 전자석을 누르면 아래 도구에서 바꿀 수 있음
- **기록하기**: 실험 판 왼쪽 위 📸 → 상단 📒 기록장에서 확인·인쇄

## 선생님 도구로 수업 링크 나눠 주기

1. 상단 👩‍🏫 **선생님** → 시작할 미션 고르기
2. 필요하면 「지금 화면의 회로를 시작 회로로 함께 보내기」, 「잠그기」, 「숫자 보이기」 선택
3. **QR 크게 보기**를 TV·칠판에 띄우거나 링크를 복사해 학급 게시판에 올리기

잠긴 링크로 들어온 학생은 그 미션만 할 수 있고 선생님 버튼이 보이지 않습니다. 잠금을 풀려면 주소의 `#` 뒷부분을 지우고 다시 열면 됩니다.

> 회로·미션 기록·기록장은 학생 기기의 브라우저에만 저장되고 서버로 보내지 않습니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm test         # 회로 계산·진단 단위 테스트
npm run build    # dist/ 에 정적 파일 생성
```

`dist/` 폴더는 어떤 정적 호스팅에도 올릴 수 있습니다. `main` 브랜치에 올리면 `.github/workflows/deploy.yml`이 GitHub Pages로 배포합니다(저장소 Settings → Pages → Source를 **GitHub Actions**로 설정해야 함).

### 구조

```
src/engine/   회로 모델, 편집(붙이기·떼기·회전), 절점 해석법 계산기, 직렬/병렬 판별, 진단
src/components/  실험 판(Workspace), 부품 그림, 전기 흐름, 설명판
src/missions.ts  미션 정의
```
