# 💡 반짝 회로 실험실

초등학교 6학년 과학 「전기의 이용」 단원을 위한 웹 회로 실험 도구입니다.
PhET *Circuit Construction Kit: DC*의 "끌어다 놓고 이어 보는" 방식을 본떠, 초등학생 눈높이와 차시 학습 목표에 맞는 기능을 더했습니다.

- **크롬북(마우스·터치패드)과 태블릿(터치) 모두 지원**: 끌기, 두 손가락 확대/축소, 휠 확대/축소, 큰 버튼
- 설치·로그인 없이 브라우저 링크로 접속, 회로는 기기에 자동 저장

## 주요 기능

| 기능 | 설명 |
|---|---|
| 🎯 미션 모드 | 차시별 미션 6개. 미션마다 필요한 부품만 꺼낼 수 있고, 목표를 이루면 자동으로 성공을 알려 줌 |
| 🔮 예상하기 | 결과를 보기 전에 먼저 예상하고, 성공하면 "내 예상 → 실제 결과"를 비교 |
| 🤔 왜 안 켜질까? | 끊긴 곳, 열린 스위치, 빠진 전구, 반대로 놓인 전지, 합선 등을 질문 → 위치 표시 순서로 단계별 힌트 |
| ⭐ 밝기 별점 | 숫자(V, A) 대신 별 0~5개로 밝기를 보여 줌. 전지 1개 + 전구 1개 = 별 3개 |
| ⚡ 전기 흐름 보기 | 움직이는 점으로 전기가 흐르는 길과 세기를 보여 줌 |
| ⚖️ 비교하기 | 회로 두 개를 나란히 만들어 밝기 비교(직렬 vs 병렬) |
| ⚠️ 합선 경고 | 전지 두 극을 바로 이으면 전선이 빨갛게 달아오르고 안전 안내 |
| 🔊 읽어 주기 | 미션·힌트를 한국어 음성으로 읽어 줌 |

### 미션 목록 (`src/missions.ts`)

1. 불을 켜라! — 전구에 불이 켜지는 조건
2. 스위치로 켜고 끄기
3. 전구 두 개를 한 줄로 (직렬) — 밝기 비교
4. 전구 두 개를 나란히 (병렬) — 밝기 비교
5. 전구 하나를 빼면? — 직렬/병렬 차이 관찰
6. 안전 탐정 — 합선된 회로 고치기

> 교과서 차시 순서에 맞추려면 `src/missions.ts`의 `MISSIONS` 배열 순서와 문구를 고치면 됩니다.

## 조작법

- **부품 꺼내기**: 부품 상자에서 끌어다 놓거나 한 번 누르기
- **연결하기**: 부품이나 전선의 끝(동그라미)을 다른 끝 가까이 가져가면 착 붙음
- **회전**: 전지·전구·스위치의 끝을 끌면 반대쪽 끝을 중심으로 돎
- **선택 도구**: 부품을 누르면 아래에 「전구 빼기」, 「방향 바꾸기」, 「지우기」 등이 나옴. 연결된 점을 누르면 「연결 떼기」
- **스위치**: 누르면 열림/닫힘
- **화면 이동/확대**: 빈 곳을 끌어 이동, 두 손가락 벌리기·휠로 확대, ⤢ 버튼으로 회로가 다 보이게
- **되돌리기**: ↶ 버튼 또는 Ctrl+Z

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm test         # 회로 계산·진단 단위 테스트
npm run build    # dist/ 에 정적 파일 생성
```

`dist/` 폴더는 어떤 정적 호스팅에도 올릴 수 있습니다. `main` 브랜치에 올리면 `.github/workflows/deploy.yml`이 GitHub Pages로 배포합니다(저장소 Settings → Pages → Source를 **GitHub Actions**로 설정해야 함).

### 구조

```
src/engine/   회로 모델, 편집(붙이기·떼기·회전), 절점 해석법 계산기, 직렬/병렬 판별, 진단
src/components/  실험 판(Workspace), 부품 그림, 전기 흐름, 설명판
src/missions.ts  미션 정의
```
