# 반짝 회로 실험실 기획안

## 1. 목적
초등 6학년 「전기의 이용」 단원의 학습 목표 도달을 돕는 웹 회로 실험 도구.
PhET *Circuit Construction Kit: DC*의 조작 방식(끌어다 놓기, 끝을 이어 연결, 전류 흐름 시각화)을 참고하되, 화면·그림·이름은 새로 만든다.

## 2. 사용 환경
- 크롬북 50%, 태블릿(아이패드·갤럭시탭) 50% → 마우스, 터치패드, 터치를 모두 지원
- 교과서: 비상교육
- 설치·로그인 없이 링크로 접속

## 3. 학습 목표 (2015 개정 성취기준 기준, 2022 개정 교과서도 같은 흐름)
1. 전지, 전선, 전구, 스위치를 연결하여 전구에 불이 켜지는 조건을 찾는다.
2. 전구의 직렬연결과 병렬연결에 따른 밝기 차이를 비교한다.
3. 전기를 절약하고 안전하게 사용하는 방법을 토의한다.
4. 전자석을 만들어 영구 자석과 비교한다.

## 4. 초등 맞춤 설계 원칙
- 수치(V, A, Ω)를 숨기고 **별점 밝기**, **흐름 속도**로 정도를 표현
- 학교 실험 키트와 같은 모양의 부품(전지 끼우개, 전구 끼우개, 집게 전선)
- **예상 → 실험 → 확인** 순서로 오개념을 드러냄
- 막혔을 때 정답 대신 **질문형 힌트 → 위치 표시** 단계별 도움
- 큰 터치 영역(44px 이상), 한국어 음성 읽기

## 5. 단계별 개발

### 1단계 (완료)
- 실험 판: 끌어다 놓기, 붙이기/떼기, 회전, 이동/확대(두 손가락, 휠), 되돌리기, 자동 저장
- 부품: 전지, 전구(빼기/끼우기), 스위치, 전선
- 미션 1~6, 예상하기, 성공 판정
- "왜 안 켜질까?" 진단
- 밝기 별점, 전기 흐름 보기, 비교하기, 합선 경고

### 2단계 (완료)
- 전자석 미션(코일 감은 횟수·전지 개수, 나침반 방향)
- 전기가 통하는 물체/통하지 않는 물체 검사
- 관찰 기록장: 회로 사진 저장, 활동지 내보내기(PDF/이미지)
- 교사가 만든 회로를 링크·QR로 나눠 주기, 미션 잠금, 전압·전류 숫자 보기(심화)
- 인터넷 없이도 열리는 앱(PWA)
- 회로도 기호 보기(심화)

### 3단계
- 교사용 반 전체 진행 현황(서버 필요)
